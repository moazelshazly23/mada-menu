# MADA – COFFEE & MORE | منيو إلكتروني + لوحة تحكم للمالك

موقع ثابت (HTML / CSS / JavaScript فقط) يعمل مجاناً على GitHub Pages. بيانات المنيو في ملف واحد `data/menu.json`، وصاحب الكافيه يعدّلها من `admin.html` وتُنشر مباشرة إلى GitHub عبر Contents API. لا يوجد Backend ولا قاعدة بيانات.

## هيكل المشروع

```
index.html          المنيو للعملاء
admin.html          لوحة التحكم (غير مرتبطة بأي رابط في المنيو)
css/style.css       تصميم المنيو
css/admin.css       تصميم لوحة التحكم
js/app.js           منطق المنيو (لغتان، بحث، أقسام)
js/admin.js         منطق لوحة التحكم
js/github-api.js    التعامل مع GitHub Contents API
data/menu.json      بيانات المنيو (المصدر الأساسي)
assets/logo.png     اللوجو الأصلي
assets/favicon.png  أيقونة الموقع
assets/images/      صور الأصناف والأقسام (يرفعها النظام تلقائياً)
```

## 1) التشغيل محلياً

لا حاجة لتثبيت أي شيء. المتصفح يمنع قراءة `menu.json` عند فتح الملف مباشرة، لذلك شغّل خادماً محلياً بسيطاً من داخل مجلد المشروع بأي طريقة:

- VS Code: ثبّت إضافة **Live Server** ثم Right click على `index.html` ← Open with Live Server.
- أو من الطرفية: `npx serve .` أو `python -m http.server 8000` ثم افتح `http://localhost:8000`.

(هذا مجرد خادم للتجربة المحلية، الموقع نفسه لا يحتاج أي خادم.)

لتجربة لوحة التحكم محلياً أدخل Owner واسم المستودع يدوياً في شاشة الدخول.

## 2) الرفع على GitHub

1. أنشئ حساباً على github.com (إن لم يكن موجوداً).
2. New repository ← الاسم مثلاً `mada-menu` ← **Public** ← Create.
3. ارفع **محتويات** المجلد (وليس المجلد نفسه) عبر Add file ← Upload files. تأكد من رفع الملف المخفي `.nojekyll` أيضاً، أو أنشئه من Add file ← Create new file.
4. Commit changes.

## 3) تفعيل GitHub Pages

Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main` / `(root)` ← Save.
بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/mada-menu/` (المنيو) و`.../admin.html` (لوحة التحكم).

اصنع QR Code لرابط المنيو من أي موقع مجاني لتوليد QR وضعه على الطاولات.

> في `index.html` غيّر `og:image` إلى الرابط الكامل للوجو (مثلاً `https://USERNAME.github.io/mada-menu/assets/logo.png`) لتظهر الصورة عند مشاركة الرابط.

## 4) إنشاء GitHub Token لصاحب الكافيه

1. GitHub ← صورة الحساب ← Settings ← Developer settings ← Personal access tokens ← **Fine-grained tokens** ← Generate new token.
2. Token name: `mada-menu-admin`، Expiration: حسب رغبتك (مثلاً سنة).
3. Repository access: **Only select repositories** ← اختر مستودع المنيو فقط.
4. Permissions ← Repository permissions ← **Contents: Read and write** (لا تحتاج أي صلاحية أخرى).
5. Generate token ثم انسخه فوراً (لا يظهر مرة ثانية). احتفظ به في مكان آمن وعلى جهازك فقط، ولا تضعه في أي ملف أو تشاركه.

## 5) استخدام لوحة التحكم

افتح `admin.html` ← أدخل اسم حساب GitHub واسم المستودع (يُملآن تلقائياً على GitHub Pages) والتوكن ← تسجيل الدخول.

| التبويب | ماذا تفعل فيه |
|---|---|
| الرئيسية | إحصائيات: عدد الأصناف، الأقسام، الظاهر، المخفي، آخر تحديث |
| الأصناف | إضافة، تعديل، نسخ، حذف، إخفاء/إظهار، ترتيب (▲▼ أو سحب وإفلات)، صورة، وصف، أسعار متعددة |
| الأقسام | إضافة، تعديل، صورة، إخفاء، ترتيب بالسحب، حذف (فقط إذا كان القسم فارغاً) |
| الإعدادات | الاسم والشعار والوصف والعبارة الترحيبية والغلاف والألوان والعملة واللغة الافتراضية وروابط التواصل |
| معاينة | المنيو بتعديلاتك قبل النشر |
| النسخ الاحتياطي | تصدير/استيراد JSON، وإلغاء المسودة |

كل تعديل يُحفظ كمسودة فقط. لا يراه العملاء إلا بعد الضغط على **نشر التعديلات** في الأعلى.

### إضافة صنف
الأصناف ← **+ إضافة صنف** ← اكتب الاسم بالإنجليزية والعربية (الاسم العربي اختياري لكن إذا تُرك فارغاً يظهر الاسم الإنجليزي للعميل، فلا توجد ترجمة آلية) ← اختر القسم ← اكتب السعر ← (اختياري) وصف وصورة ← حفظ ← **نشر التعديلات**.

### صنف له سعران
في نافذة الصنف اضغط **+ إضافة خيار سعر** واكتب اسم الخيار (مثل `Single` و`Double`) وسعر كل خيار. اترك سعر الخيار غير المتاح فارغاً فلن يظهر (ولن يظهر صفراً).

### تعديل سعر
الأصناف ← اختر القسم ← **تعديل** بجوار الصنف ← غيّر السعر ← حفظ ← **نشر التعديلات**.

### بعد النشر
تظهر رسالة نجاح خضراء فقط بعد تأكيد GitHub للحفظ. يحتاج GitHub Pages من دقيقة إلى دقيقتين لعرض النسخة الجديدة، ثم حدّث صفحة المنيو. في حال حدوث خطأ (اتصال، صلاحيات، تعارض) تظهر رسالة واضحة وتبقى تعديلاتك محفوظة في اللوحة لإعادة المحاولة.

### الصور
تُصغَّر وتُضغَّط تلقائياً داخل المتصفح قبل الرفع (حتى 800px للأصناف والأقسام و1600px للغلاف) وتُرفع إلى `assets/images/` وتُحمَّل في المنيو بـ Lazy Loading.

## 6) الأمان (مهم)

- GitHub Pages لا يوفر Backend أو تسجيل دخول من جهة الخادم. الحماية الفعلية هي **التوكن**: من لا يملكه يستطيع رؤية صفحة الدخول فقط ولا يستطيع تعديل أي شيء.
- التوكن يُحفظ في `sessionStorage` فقط، ويُمسح عند «تسجيل الخروج» أو إغلاق التبويب. لا يُكتب في أي ملف ولا في Local Storage ولا في المستودع.
- استخدم Fine-grained token لمستودع المنيو فقط وبصلاحية Contents فقط، وحدّد له تاريخ انتهاء. إذا ضاع أو انكشف احذفه فوراً من إعدادات GitHub وأنشئ بديلاً.
- هذه الآلية تعتمد على حماية التوكن وسلامة كود الموقع، وليست بديلاً عن نظام مصادقة كامل على خادم. لا تفتح لوحة التحكم على جهاز عام.
- المستودع Public، فملف `menu.json` وكل الصور عامة (وهذا المطلوب للمنيو).

## 7) ملاحظات

- المصدر الأساسي للبيانات هو `data/menu.json` في GitHub. Local Storage لا يُستخدم لحفظ المنيو. المسودة غير المنشورة تُحفظ مؤقتاً في `sessionStorage` فقط لحمايتها من إعادة تحميل الصفحة.
- إذا عُدّل `menu.json` من مكان آخر أثناء عملك، تظهر رسالة تعارض قبل النشر وتختار بين الاستبدال والإلغاء.
- الأسماء العربية للأقسام والأصناف فارغة في البيانات الأولية عمداً (لم تُترجم آلياً). أضفها من لوحة التحكم، وعندها تظهر عند تبديل اللغة إلى العربية.
- الخطوط (Cormorant Garamond, Amiri, Jost, Cairo) تُحمَّل من Google Fonts مع بدائل نظام إذا لم تتوفر.
